# Difficulty Framework

Difficulty is a vector, not a traffic-size label.

| Dimension | 1 | 3 | 5 |
| --- | --- | --- | --- |
| Conceptual | direct prerequisite recall | combines several concepts | novel synthesis and contested trade-offs |
| Implementation | localized implementation | multi-component correctness | production-quality behavior under failure |
| Scale | single process | distributed service | multi-region or fleet-wide constraints |
| Ambiguity | requirements explicit | material discovery required | goals and ownership are contested |
| Prerequisite depth | introductory | experienced practitioner | deep specialist context |

## Editorial labels

- Foundational: establish prerequisite fluency.
- Intermediate: apply a known method with meaningful edge cases.
- Advanced: combine concepts, justify trade-offs, and handle failures.
- Staff: resolve ambiguity across systems and teams; own migration and operations.
- Principal: set durable technical direction across organizational boundaries with governance, cost, and risk.

Initial target counts are 135 foundational, 270 intermediate, 473 advanced, 337 staff, and 135 principal. Labels remain `provisional` until technical review and become `empirical` only after adequate performance data and bias checks.
