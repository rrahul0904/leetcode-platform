# Solution Schema

A complete solution contains a reference approach, detailed explanation, alternatives, decision trade-offs, optional executable complexity claims, testing/debugging guidance, production follow-ups, critical omissions, a strong response example, and a branching interviewer guide.

Executable modes additionally require isolated runtime tests. Open-ended modes require architecture artifacts, capacity reasoning, failure analysis, security/privacy, cost, migration, ownership, and requirement-change responses in the question specification and rubric.

A solution is never considered valid solely because it parses against the schema.
