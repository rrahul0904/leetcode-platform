# MVP Plan

1. Foundation: audited requirements, taxonomy, schemas, manifest, docs, locks, and validation.
2. Catalog slice: OIDC principal contract, onboarding, PostgreSQL schema, publication sync, candidate-safe search/detail, and admin draft workflow.
3. Execution slice: Python and SQL controller contracts followed by production-equivalent isolated Jobs and security evidence.
4. Evaluation: submissions, deterministic results, rubric evidence, and AI gateway behind consent.
5. Design workspaces: modeling, architecture, and documents with autosave/recovery.
6. Interviews and learning: state machine, transcript evidence, plans, retention, and readiness confidence.

The first content batch should contain 10–20 exemplary packages across modes before scaling to 100. This validates schema and review economics; it does not alter the Milestone 1 requirement for 100 validated questions.
