# Database Schema

PostgreSQL 18 is the system of record. UUIDv7-compatible identifiers are generated by the application until an approved database-native method is verified.

## Identity and tenancy

`users`, `organizations`, `organization_memberships`, `roles`, `permissions`, `role_permissions`, `user_profiles`, `consent_records`, `subscriptions`, and `entitlements`.

## Content

`questions` stores stable identity and current publication pointer. `question_versions` stores versioned prompt metadata and structured variable content. Normalized relations include `tracks`, `skills`, `question_skills`, `role_tags`, `question_roles`, `company_style_tags`, `question_company_tags`, `learning_objectives`, `prerequisites`, `question_variants`, `examples`, `constraints`, `starter_code`, `test_suites`, `test_cases`, `solutions`, `alternative_solutions`, `complexity_analyses`, `hints`, `rubrics`, `rubric_dimensions`, `follow_ups`, `common_mistakes`, `interviewer_guides`, and `architecture_artifacts`.

## Workflow and quality

`validation_runs`, `validation_findings`, `similarity_results`, `review_assignments`, `review_decisions`, `review_comments`, `publication_events`, and `provenance_records`. Review decisions are append-only. Publication events include source Git revision and content hash.

## Candidate evidence

`submissions`, `execution_runs`, `test_results`, `interviews`, `interview_events`, `evaluation_runs`, `dimension_scores`, `evidence_excerpts`, `learning_plans`, `learning_plan_items`, `mastery_estimates`, `review_schedule`, and `design_documents`.

## Platform operations

`ai_usage`, `outbox_events`, `idempotency_records`, and append-only `audit_events`. Large logs, recordings, exports, and document binaries live in S3 with PostgreSQL metadata.

## Integrity and search

- Stable IDs and slugs are unique; versions are unique by `(question_id, version)`.
- A partial unique index permits only one current published version per question.
- Foreign keys prevent broken prerequisites and relationships; application validation prevents prerequisite cycles.
- Lexical search uses generated `tsvector`, spelling tolerance uses `pg_trgm`, and configurable embeddings use pgvector with provider/model/version/dimension/hash metadata.
- Tenant tables carry `organization_id` and use RLS with transaction-local tenant context.
