# Company-style Track Matrix

Company-style tags are independent curriculum lenses based on public themes. They do not claim affiliation or that a question appeared in an interview.

| Lens | Emphasis |
| --- | --- |
| OpenAI-style | AI infrastructure, evaluation, agents, product engineering, safety, reliability |
| Anthropic-style | reliable/safe AI, alignment infrastructure, misuse prevention, research engineering |
| Scale AI-style | training data, human-in-loop workflows, data quality, evaluation, enterprise deployment |
| Google/DeepMind-style | algorithms, distributed compute, ML/research depth, reliability |
| Meta-style | algorithms, graphs, feeds, messaging, ads, large-scale product systems |
| Amazon-style | ownership, customer impact, operations, cost-aware design, written decisions |
| Netflix-style | recommendations, experimentation, streaming, resilience, observability |
| NVIDIA-style | GPU systems, training, serving, scheduling, memory/compute efficiency |
| Databricks/Snowflake-style | engines, storage formats, metadata, governance, optimization |
| Stripe-style | APIs, ledgers, idempotency, developer experience, correctness, risk |

Additional lenses—Microsoft, Uber, Airbnb, Apple, LinkedIn, Palantir, Cloudflare, Coinbase, TikTok/ByteDance, DoorDash, Pinterest, Bloomberg, and emerging AI organizations—use the same evidence-note policy. A question can join multiple tracks, but the track curator must record why.
