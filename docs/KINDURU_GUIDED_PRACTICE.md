# Kinduru-inspired guided practice

## Source reviewed

Public product reference: https://kinduru.com/ and https://kinduru.com/how-it-works

Kinduru's useful product patterns for SkillForge are the predictable five-step learning rhythm, one clear next step, autosaved progress, support without penalty, and a calmer self-paced experience. The coding product adapts those interaction ideas rather than copying Kinduru's curriculum, visual identity, wording, or parent/child product model.

## SkillForge mapping

| Source pattern | SkillForge adaptation |
| --- | --- |
| Study Material | Study: surface the published learning objectives before coding |
| Discover | Discover: focus attention on public constraints and boundary conditions |
| Practice | Practice: require a short candidate-authored approach/complexity explanation before optional stage signoff |
| Create | Create: direct the candidate into the existing secure coding, Run, and Submit workflow |
| Challenge | Challenge: prompt scale, streaming, latency, memory, and trade-off reasoning |
| Helping Hands | Guided nudge: static Socratic scaffolding that does not alter evaluation or score |
| Pause and return | Stage completion, reflection, and focus preference persist in browser storage; the existing practice draft remains server-autosaved |
| Structure without pressure | Candidate can hide the visible timer while elapsed session state continues to persist normally |

## Safety and truthfulness boundaries

- Guided stage completion is not mastery evidence and does not change readiness scores.
- Guided nudges do not expose hidden tests, expected answers, reference solutions, or answer keys.
- Run and Submit still use the existing isolated execution and deterministic evaluation path.
- The AI Tutor remains the existing candidate-owned Socratic coaching surface; this slice does not introduce a second tutor backend.
- Hiding the timer changes presentation only. It does not stop or rewrite elapsed-time persistence.
- Browser-local guided progress is intentionally lightweight in this first slice and is not claimed as durable account-backed learning history.

## Follow-on opportunities

A later slice can promote guided stage events to the existing candidate-owned tutor/session model, add evidence-backed reviewer signoff for mock interviews or mentor workflows, and use completed challenge reflections as optional coaching context. Those are intentionally outside this first implementation so the initial feature stays isolated and truthful.
