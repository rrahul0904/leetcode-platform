# Cost Model

No cloud price is hard-coded before region, contract, and current official pricing are verified. Cost categories are ECS web/API, EKS sandbox baseline and burst nodes, RDS PostgreSQL, Valkey, S3/transfer, Temporal Cloud, observability ingestion/retention, Cognito MAUs, provider AI tokens, email, WAF, and security services.

Unit economics track cost per active learner, execution, SQL attempt, mock interview, AI evaluation, stored recording, and published content package. Tenant budgets, sandbox quotas, model routing, caching, retention, and batch scheduling are primary controls. A dated calculator with official regional prices is required before production approval.
