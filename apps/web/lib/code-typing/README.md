# Code typing practice

Phase A is a static, browser-only text transcription module. It must not execute typed input or call submission/assessment APIs. Its six Python, SQL, and JavaScript snippets are first-party text authored for Rigor; the repository has no standalone content license, so they are limited to this product until the product owner selects an explicit public content license. No donor code, screenshots, dictionary, assets, layout, or branding are included. Snippet provenance and this boundary are recorded with each version.

Attempts are transient while typing and the last 30 completed or timed-out summaries stay in this browser. The module never stores the typed text and never sends attempts to a server. It remains a bounded guest practice surface until account-backed history is deliberately designed and reviewed.
